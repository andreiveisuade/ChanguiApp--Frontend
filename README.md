# ChanguiApp — Frontend

Aplicación móvil en React Native para Android que permite a consumidores argentinos controlar el total de su compra en tiempo real escaneando productos con la cámara del celular.

## Stack

- React Native
- MVVM + Repository
- Firebase Auth (Google Sign-In + email/contraseña)

## Requisitos

- Node.js >= 18
- React Native CLI
- Android Studio + emulador o dispositivo físico

## Setup

```bash
npm install
npx react-native run-android
```
